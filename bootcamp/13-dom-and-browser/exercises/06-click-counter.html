concepts: addEventListener · state in a variable · exercises/06-click-counter.html

Three buttons, one number. setup() wires them up:

  • #inc adds 1, #dec subtracts 1
  • the count never goes below 0
  • #reset-count puts it back to 0
  • #count always shows the current number
  • when the count reaches 5 or more, #count gets the class high — and loses it again below 5

Keep the number in a variable. Reading it back out of the DOM with Number(count.textContent) works right up until the text says "5 clicks" instead of "5".

hint: write one paint() function that renders the current value, and have every handler change the variable then call it.
