07 · Live mirror and counter ★☆☆ warm-up

concepts: input event · live preview · attributes · exercises/07-input-mirror.html

Wire the input event on #bio so that, on every keystroke:

  • #preview shows what was typed — or the words Nothing typed yet when the box is empty
  • #counter shows 12 / 60 — characters typed, then the limit
  • the limit is read from the input's maxlength attribute, not typed into your code
  • #counter gets the class warn when 10 or fewer characters remain, and loses it again

setup() paints that starting state immediately — an empty box should already read 0 / 60.

hint: input fires on every change including paste and delete; keyup misses paste-by-mouse. Read the limit with Number(input.getAttribute('maxlength')).
