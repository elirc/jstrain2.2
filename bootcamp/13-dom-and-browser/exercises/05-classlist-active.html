05 · Classes and the active item ★★☆ core

concepts: classList · aria-pressed · state in the DOM · exercises/05-classlist-active.html

Two little widgets, both driven by classList.

The nav: clicking a .nav-btn gives it the class active and takes that class off every other button — exactly one active item, always. #current then reads Viewing: docs (the button's data-view).

The compact toggle: #compact flips the class compact on #panel, and keeps its own label and aria-pressed in sync: Compact mode: on / Compact mode: off.

setup() also paints the starting state: nothing active, compact off.

hint: "remove the class from everyone, then add it to one" beats tracking which button was previously active. el.classList.toggle('x') returns true when it just added the class.
