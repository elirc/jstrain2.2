30 · Themes as custom properties ★★☆ extra

concepts: CSS custom properties · data attributes · localStorage · exercises/30-theme-tokens.html

Exercise 16 flipped one class. This is how a real theme switcher works: the stylesheet reads var(--page), and JavaScript only ever changes the values of those variables.

  • apply(name) writes every token of THEMES[name] onto document.documentElement.style with setProperty
  • it also sets data-theme on the same element, writes the name into #theme-label, and marks the chosen button with the class active and aria-pressed="true" — the others go to "false"
  • the choice is saved under THEME_KEY and restored on load, all storage calls in try/catch
  • a saved name that is not a theme falls back to light

hint: check the saved name with Object.prototype.hasOwnProperty.call(THEMES, saved), not saved in THEMES — 'constructor' in THEMES is true, and that "theme" is a function.
