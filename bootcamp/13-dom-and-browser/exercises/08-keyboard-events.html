08 · Enter submits, Escape clears ★★☆ core

concepts: keydown · event.key · event properties · exercises/08-keyboard-events.html

Listen for keydown on #entry and read the event object:

  • every key press updates #last-key to key=a shift=false — the real event.key and event.shiftKey
  • Enter (without Shift) with a non-blank value: append <li class="entry"> with the trimmed text to #entries, then empty the box
  • Shift+Enter adds nothing — that combination means "new line", not "submit"
  • Escape empties the box and adds nothing
  • blank or whitespace-only + Enter: nothing happens

hint: event.key is a string — 'Enter', 'Escape', 'a', ' '. Not a number, and event.keyCode is dead. Check the modifier flags before you act.
