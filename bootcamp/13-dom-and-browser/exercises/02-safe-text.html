02 · Text, not markup ★☆☆ warm-up

concepts: textContent vs innerHTML · XSS · exercises/02-safe-text.html

Render COMMENTS into #feed. Two of those comments were written by people trying to break your page.

For every comment build:

<article class="comment"><h3>author</h3><p>text</p></article>

The rule: whatever a user typed must appear on screen as characters. If someone types <img src=x onerror=...> the reader should see that text — the browser must not build an image element out of it.

hint: innerHTML parses a string as HTML. textContent puts the string in as text and escapes it for you. One of those two is safe with input you did not write.
