03 · Render a list from data ★☆☆ warm-up

concepts: createElement · append · empty state · exercises/03-render-list.html

Turn an array of objects into DOM nodes. renderCrew(list) fills #crew with one item per crew member:

<li class="crew-item" data-id="a1"><span class="name">Ada</span><span class="role">pilot</span></li>

  • same order as the array
  • data-id comes from member.id
  • empty array → no <li> at all, and #empty becomes visible
  • non-empty → #empty stays hidden

hint: el.dataset.id = 'a1' writes the attribute. To show or hide a node without touching CSS, set the hidden property: el.hidden = false.
