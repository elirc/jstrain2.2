A stopwatch that counts in tenths of a second.

  • #start begins ticking: a setInterval every 100ms that adds one tenth
  • #display reads 1.4s — one decimal, always
  • #stop stops the interval, leaving the value on screen
  • #start after a stop resumes from that value
  • #reset-sw stops and returns to 0.0s
  • #sw-state reads running or stopped
  • pressing start twice must not run the clock twice as fast

hint: keep the id from setInterval in a variable and treat null as "not running". Guard start with if (timer !== null) return; — the second interval from a double click has no id you can reach, so it ticks forever.
