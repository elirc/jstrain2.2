28 · An editor that can take it back — SOLUTION ★★☆ extra

concepts: snapshot stack · disabled state · bounded history · solutions/28-undo-editor.html

A textarea with an Undo button behind it.

  • every input event pushes the text as it was before that edit onto a history array
  • #undo pops the newest snapshot back into the textarea, and is disabled whenever the history is empty
  • #clear-text empties the field — and is itself undoable
  • #undo-count reads 3 snapshots, or 1 snapshot for one
  • the history never grows past MAX_HISTORY: drop the oldest entry instead

hint: keep a last variable holding what is currently on screen. On input, push last (the old text), then update it. Push the new value instead and the first undo appears to do nothing at all — it puts back what is already there.
