concepts: debounce · closures · filtering · solutions/18-debounce-search.html

Filter a list as the user types — but not on every keystroke.

  1. Write debounce(fn, ms): it returns a new function that waits until ms have passed with no further calls, then runs fn once.
  2. setup() renders all of FRUIT as <li class="fruit">, then filters on input — case-insensitive substring match — through a 150ms debounce.
  3. #matches reads showing 4 of 12, or no matches when nothing matches.
  4. Every render bumps a counter: #renders reads renders: 3. The first render at setup counts as 1.

hint: the returned function closes over one timer id. clearTimeout the previous one on every call, then set a new one. That is the entire pattern — five lines.
