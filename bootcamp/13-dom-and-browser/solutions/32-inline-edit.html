32 · Edit in place — SOLUTION ★★☆ extra

concepts: dblclick · Enter commits · Escape cancels · solutions/32-inline-edit.html

Double-click a note, it becomes an input. Enter keeps the change, Escape throws it away.

  • render NOTES as <li class="note"><span class="label">…</span></li>
  • dblclick on a label turns that row into <input class="edit"> holding the current text, adds the class editing, and focuses it. Only one row edits at a time
  • Enter writes the value back into the array and rerenders; a blank value is treated as a cancel
  • Escape puts the row back untouched
  • #notes-state shows the notes joined with " | " — proof that the data changed, not just the row

hint: keep the row being edited as an index in state and let render() decide span-or-input. The keydown listener is delegated on the list, because the input does not exist yet when you attach it.
