26 · A menu you can drive with the keyboard — SOLUTION ★★☆ extra

concepts: ArrowUp / ArrowDown · wrapping index · roving active · solutions/26-keyboard-menu.html

The same dropdown as exercise 15, except a keyboard can use it.

  • #menu-open opens and closes #action-menu and keeps aria-expanded in step
  • opening puts the class active on the first item — exactly one item is active at any moment
  • ↓ moves the active item down, ↑ up, and both wrap around the ends
  • Enter runs the active item: its data-action goes into #last-action and the menu closes. A click on an item does the same
  • Escape closes and runs nothing. While the menu is closed the keys do nothing at all

hint: keep the highlight as an index into the items and repaint from it. (index + step + items.length) % items.length wraps both directions in one expression — plain index - 1 reaches -1, and items[-1] is undefined, which throws one line later. The listener goes on document, because nothing inside the menu has focus.
