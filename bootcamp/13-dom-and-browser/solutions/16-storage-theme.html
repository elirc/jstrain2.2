16 · Remember it after a reload — SOLUTION ★★☆ core

concepts: localStorage · try/catch · persistence · solutions/16-storage-theme.html

Two things that must survive a refresh, both stored in localStorage.

  • Visits — key dom.visits. setup() reads it and shows it in #visits; #bump adds one and saves. Missing or corrupt value → start at 0.
  • Theme — key dom.theme, either 'dark' or 'light'. setup() applies it: the class dark on <body> and the name in #theme-name. #theme-toggle flips it and saves.

Wrap every single storage call in try/catch. Private windows, "block third-party cookies", a full quota — any of them make localStorage throw, and a counter is not worth a broken page.

hint: everything comes back as a string or null. Number(null) is 0 but Number('banana') is NaN, so check with Number.isFinite before trusting it.
