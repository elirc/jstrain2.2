09 · Event delegation, part 1 — SOLUTION ★★☆ core

concepts: event delegation · closest · bubbling · solutions/09-delegation-delete.html

Event delegation is the pattern: instead of a listener on every child, put one listener on the parent and work out what was clicked from event.target. Events bubble up, so the parent hears them all — including clicks on children that did not exist when you attached it.

setup() must attach exactly one click listener, on #shopping:

  • a click on a .del button removes that button's <li>
  • a click anywhere else in the list does nothing
  • #left always reads 3 items — and 1 item, singular, when only one is left
  • #add-item appends a new row with the same shape: a .label span reading Item N (N = the new length) and a .del button

hint: event.target is the deepest element clicked. event.target.closest('.del') walks up from it and returns null if there is no match — that null check is your filter. button.closest('li') then finds the row to remove.
