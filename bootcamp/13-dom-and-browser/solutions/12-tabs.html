concepts: components · aria-selected · hidden · solutions/12-tabs.html

Build a tab strip. setup() selects the first tab, then clicking any tab selects it:

  • the selected tab gets the class active and aria-selected="true"; every other tab loses the class and gets aria-selected="false"
  • the panel whose data-panel matches the tab's data-tab is shown; the rest are hidden
  • hide with the hidden property — panels stay in the document, they are not deleted

hint: one select(name) function that loops over all tabs and all panels and sets the correct state for each. Call it from a delegated click listener on #tablist, and once at the end of setup with the first tab's name.
