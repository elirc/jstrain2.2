19 · A router in 20 lines — SOLUTION ★★☆ core

concepts: location.hash · hashchange · views · solutions/19-hash-router.html

Three "pages", no server, no page loads. The URL fragment is the state.

  • read the route from location.hash: #/notes → notes; an empty hash → home
  • render into #view: an <h2> with the route's title and a <p> with its body (clear the view first)
  • an unknown route renders <h2>Not found</h2>, and #route-name reads not-found; otherwise #route-name is the route key
  • the matching #router-nav link gets the class active — only one
  • re-render on every hashchange, and once at setup() for the route the page loaded with

hint: location.hash includes the # (and here the slash): strip both with location.hash.replace(/^#\/?/, ''). Clicking the links changes the hash for free — the browser does not reload for a fragment change, it fires hashchange.
