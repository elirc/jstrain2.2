13 · Accordion — SOLUTION ★★☆ core

concepts: components · aria-expanded · one-open · solutions/13-accordion.html

Three questions, at most one answer open.

  • everything starts closed
  • clicking a .q opens its answer: the sibling .a becomes visible, the button gets aria-expanded="true", and the surrounding .item gets the class open
  • opening one closes any other that was open
  • clicking the open question closes it — so "none open" is a valid state

hint: work out the target state first (const willOpen = !item.classList.contains('open')), then close everything, then open the one item if willOpen. Trying to close others and toggle the clicked one in the same pass gets confusing fast.
