concepts: delegation · data-action · DOM moves · solutions/10-delegation-actions.html

Same pattern, more work per click. Every button in the list carries a data-action; one listener on #tasks reads it and dispatches.

  • toggle → flip the class done on that row
  • delete → remove that row
  • up → move that row above the one before it (the first row does not move)
  • a click that is not on an action button changes nothing
  • after every action #task-status reads 1 of 3 done

hint: const button = event.target.closest('[data-action]'), then switch (button.dataset.action). To move a node up: row.previousElementSibling gives the neighbour, and list.insertBefore(row, neighbour) moves the row — appending an element that is already in the document moves it, it never copies.
