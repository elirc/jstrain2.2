04 · Build a table, twice — SOLUTION ★★☆ core

concepts: createElement · clear-and-rerender · solutions/04-table-and-rerender.html

renderTable(rows) builds a whole table inside #table-host:

  • one <table id="scores"> with a <thead> row of Name and Score (use <th>)
  • a <tbody> with one <tr> per row, two <td>s: name, then score
  • rows with a score of 90 or more get the class top on the <tr>

The clear-and-rerender pattern: calling renderTable again must replace what is there, never append to it. Wipe the host first, then build. That one habit is what stops a UI from slowly filling up with ghost rows.

hint: host.textContent = '' empties a container. classList.toggle('top', score >= 90) adds or removes in one call.
