# 21 — interleaved drills mastery bank

Deepen: retrieval, transfer, discrimination, estimation, mixed practice, and clear technical explanation across the whole stack.

## Explain

- [ ] From memory, explain value/reference behavior, closures, promises, HTTP, and transactions in five minutes.
- [ ] Compare validation, error handling, and testing at UI, API, domain, and persistence boundaries.
- [ ] Explain when a loop, array method, map/set, queue, stream, or SQL query is the best abstraction.
- [ ] Explain one end-to-end request from browser event through storage and back to rendered state.
- [ ] Explain how you decide whether AI output is trustworthy enough to keep.

## Predict

- [ ] Predict outputs for a mixed snippet involving coercion, closure capture, mutation, and async ordering.
- [ ] Predict failures introduced by adding a required field across React, API, domain, and database layers.
- [ ] Predict time and space growth for five small solutions before benchmarking them.
- [ ] Predict the observable behavior of timeout, retry, cancellation, and duplicate submission together.
- [ ] Predict which test layer catches each of ten supplied defects most cheaply and reliably.

## Implement

- [ ] Solve five 15-minute mixed drills without topic labels, then classify the knowledge each required.
- [ ] Implement one feature three ways and justify the simplest design that meets the constraints.
- [ ] Convert a synchronous collection pipeline into bounded async processing with equivalent results.
- [ ] Add a field across a small full-stack slice, including migration, compatibility, and tests.
- [ ] Rebuild a prior exercise from a blank file after seven days without consulting the solution.

## Test

- [ ] Write tests for an unfamiliar function using only its contract and discovered equivalence classes.
- [ ] Design one unit, integration, contract, and end-to-end test for the same business behavior.
- [ ] Create a metamorphic test where transformed input implies a predictable transformed result.
- [ ] Test a mixed async/storage workflow using controlled time and injected failures.
- [ ] Audit an old solution: add the three highest-value missing tests and explain their risk coverage.

## Debug and review

- [ ] Time-box a mixed bug hunt: reproduce, narrow, hypothesize, instrument, fix, and regress in 45 minutes.
- [ ] Review unfamiliar code for correctness, complexity, security, operability, and maintainability.
- [ ] Diagnose a failure spanning React state, HTTP serialization, and database null handling.
- [ ] Compare your solution with an AI solution and retain only changes you can independently defend.
- [ ] Write a blameless incident note for a drill failure, including detection and prevention improvements.

## Apply

- [ ] Complete a 90-minute simulated ticket with ambiguous requirements and write assumptions first.
- [ ] Pair with AI in navigator mode, then reproduce the feature unaided the next day.
- [ ] Make a small legacy change while keeping its external contract stable and shrinking complexity.
- [ ] Give a five-minute design review covering alternatives, risks, testing, rollout, and rollback.
- [ ] Use results from all 30 drills to select three weak areas and schedule spaced remediation.
